# Alphavista Imóveis — site

Site one-page da Alphavista Imóveis (Advisor: Denis Rabbi).
**Análise • Estratégia • Execução** — *O luxo mudou de endereço.*

Site estático (HTML + CSS + JS), pronto para a Vercel — sem build.

## Estrutura
- `index.html` — página completa
- `js/main.js` — cursor, tilt 3D, botões magnéticos, contadores
- `js/lenis.min.js` — scroll suave (Lenis, MIT)
- `img/` — fotos e logo

## Pendências de conteúdo
Substituir no `index.html`: números do case e do VGV (`XX`), número do WhatsApp (`55XXXXXXXXXXX`), QR Code real, `[CRECI]` e `[LOCALIZAÇÃO]`.

## Deploy
Importe o repositório em vercel.com/new (Framework: *Other*, sem build command).
